Basic table

Basic tables use the .table class for standard data display.

# Name Email Status
1 John Doe john@example.com Active
2 Jane Smith jane@example.com Inactive

Striped rows

Striped tables use .table-striped to add zebra-striping to table rows.

# Product Price Stock
1 MacBook Pro 16" $2,499 In stock
2 Magic Mouse 2 $79 Out of stock
3 AirPods Max $549 In stock

Use .table-striped-columns to add zebra-striping to table columns.

Use contextual classes like .table-primary , .table-success , .table-danger on rows or cells.
